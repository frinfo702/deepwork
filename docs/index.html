Features

Allow what matters.
Everything else can wait.

Forget maintaining an endless blocklist. You decide what stays, and during focus time the rest simply gets out of the way.

🗓

Weekly schedules

Set up as many blocks as you like, such as weekdays 9–12 and 13–18. Late-night sessions that cross midnight work too.

⏱

Quick focus

Start a 25, 50 or 90 minute session in one click, and extend it the same way. Pause when you're interrupted, and resume right where you left off.

🧩

App allow list

Apps not on your list quit as soon as they launch, or you can just hide them. Unsaved work is never thrown away.

🌐

Site allow list

Deepwork checks your browser tabs every second and swaps anything not on the list for a calm block page, or closes the tab. No extension needed.

🔒

Strict mode

Lock settings, stopping and quitting until the session ends. A promise to your future self.

🍅

Pomodoro, your way

Focus rounds with short and long breaks in between. Set every length, how often the long break comes, how many rounds to run, and whether each phase starts on its own.

📊

Today at a glance

See how long you've focused today and how many distractions were blocked, right from the menu bar. A gentle notification marks each start, break and end.

☁️

Launch at login, stays updated

Deepwork waits in your menu bar every time your Mac starts, and updates itself in one click when a new version ships.

Install

Up and running
in a minute.

Deepwork is an indie app that isn't notarized by Apple yet, so macOS asks once before opening it.

Download & move

Unzip Deepwork.zip and drag Deepwork.app into your Applications folder.

Allow it once

If macOS blocks it, open System Settings › Privacy & Security and click Open Anyway. You can also run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Deepwork.app

Choose what stays

Click the ☁️ in your menu bar and open Settings… to set your schedules and your allowed apps and sites. The first session asks for Automation access to your browser.

FAQ

Questions, answered.

How does it block sites without a browser extension?

Safari, Chrome, Arc, Dia, Edge, Brave, Vivaldi, Opera and Orion have an AppleScript interface. Every second, Deepwork reads the URL of the visible tab in each window. If the domain isn't on your list, it swaps the tab for a block page or closes it.

Does it work with Firefox?

Firefox has no AppleScript access to its tabs, so its sites can't be filtered. Block Firefox under Apps and browse in one of the supported browsers during focus time.

Does Deepwork send my data anywhere?

No. The only network request Deepwork makes is checking GitHub for a new release, and you can turn that off in Settings. Your settings and stats stay on your Mac.

How do updates work?

Deepwork checks GitHub Releases at launch and every few hours. When a new version is out, an Install button shows up in the menu bar panel. One click downloads it, swaps the app and relaunches. Updates are held back while strict mode is locking a session.

It closed my terminal and editor during focus time.

Every app that isn't on your list is affected. Add the tools you work with in the Apps tab of Settings. You can pick them from the apps that are running.

What if I really need to stop?

With strict mode off, you can pause, reset or quit from the menu bar at any time. With strict mode on, you wait until the session ends, so try it with strict mode off first.

Can I build it from source?

Yes. With the Xcode Command Line Tools installed, clone the repo and run ./build.sh to get build/Deepwork.app.
