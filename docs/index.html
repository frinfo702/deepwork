Features

気が散るものを、時間ごと遠ざける。

Deepwork はブロックするものではなく、許可するものを決めます。集中中は、決めたもの以外が静かに消えていきます。

🗓

曜日ごとのスケジュール

「平日 9:00–12:00」「13:00–18:00」のように、スケジュールをいくつでも組めます。日付をまたぐ夜の時間帯にも対応しています。

⏱

クイック集中

25分・50分・90分をワンクリックで始められます。延長もワンクリック。時間は設定で自由に変えられます。

🧩

アプリの許可リスト

許可していないアプリは、起動した瞬間に終了します。「隠すだけ」も選べます。未保存のデータが勝手に消えることはありません。

🌐

サイトの許可リスト

Dia で開いたタブを毎秒チェックし、許可していないサイトはブロック画面に差し替えるか、タブを閉じます。拡張機能はいりません。

🔒

厳格モード

オンにすると、集中が終わるまで設定の変更・停止・終了ができなくなります。未来の自分との約束です。

📊

今日の記録

今日どれだけ集中できたか、何回誘惑をブロックしたかがメニューバーからすぐ見られます。

🔔

開始と終了の通知

スケジュールが始まるときと終わるときに通知します。休憩のタイミングを逃しません。

☁️

ログイン時に自動で起動

一度設定すれば、Mac を起動するたびにメニューバーで待機します。軽量で、Dock を占領しません。

Install

1分で始められます。

Deepwork は Apple の公証を受けていない個人開発のアプリです。初回だけ、macOS に開いてよいと伝える必要があります。

ダウンロードして移動

Deepwork.zip を展開し、Deepwork.app を「アプリケーション」フォルダに入れます。

初回だけ許可する

開こうとしてブロックされたら、システム設定 › プライバシーとセキュリティ の「このまま開く」を押します。ターミナルでも許可できます。

xattr -dr com.apple.quarantine /Applications/Deepwork.app

許可するものを選ぶ

メニューバーの ☁️ から「設定…」を開き、スケジュールと、許可するアプリ・サイトを決めます。初めての集中タイムでは、Dia の「オートメーション」の許可を求められます。

FAQ

よくある質問

ブラウザ拡張なしで、どうやってサイトを止めているのですか？

Dia が備えている AppleScript のインターフェースを使って、各ウィンドウで表示中のタブの URL を1秒ごとに読み取っています。許可していないドメインなら、ブロック画面に差し替えるか、タブを閉じます。

Dia 以外のブラウザでも使えますか？

サイトの許可リストは今のところ Dia 専用です。ほかのブラウザも、許可アプリに入れなければブラウザごとブロックされるので、集中中は Dia だけを使う運用ができます。

データはどこかに送られますか？

送られません。Deepwork はネットワーク通信を一切しません。設定と記録は、すべてお使いの Mac の中だけに保存されます。

集中中にターミナルやエディタまで閉じられてしまいます。

集中中は、許可リストにないアプリがすべて対象になります。仕事で使うアプリは、設定の「アプリ」タブで追加してください。実行中のアプリから選んで追加することもできます。

どうしても止めたいときは？

厳格モードがオフなら、メニューバーからいつでも停止・終了できます。厳格モードがオンのときは、終了時刻まで待つことになります。気軽に試すときは、まずオフのまま使ってください。

ソースからビルドできますか？

できます。Xcode Command Line Tools があれば、リポジトリを clone して ./build.sh を実行するだけで build/Deepwork.app ができます。
